# Self-hosted fonts

These variable fonts are bundled so the build never has to download anything from Google Fonts
(that download failed intermittently on GitHub's runners and broke deploys).

| File | Font | License |
|---|---|---|
| `inter-latin-wght-normal.woff2` | Inter (variable, latin) | SIL Open Font License 1.1 |
| `plus-jakarta-sans-latin-wght-normal.woff2` | Plus Jakarta Sans (variable, latin) | SIL Open Font License 1.1 |
| `noto-naskh-arabic-arabic-wght-normal.woff2` | Noto Naskh Arabic (variable, arabic), used on `/urdu` | SIL Open Font License 1.1 |

Source: the `@fontsource-variable/*` npm packages (files copied unchanged).
